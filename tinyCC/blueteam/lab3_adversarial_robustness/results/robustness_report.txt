     'audit/CWE/advisory/threat-model' evade detection while still
     extracting actionable vulnerability intelligence.

  • Lab 2: Add semantic similarity scoring against known vulnerability
    advisory templates. Flag CWE-annotated code regardless of context.
  • Pipeline: Add conversation-level analysis — multi-turn escalation
    patterns (benign → technical → exploit) should raise score over
    successive turns even if each individual turn looks safe.
